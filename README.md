# AR ตามพิกัด (Location-based) · 0214381 Lab 3

Template แสดงตัวละคร 3D สามจุดรอบตำแหน่ง GPS แรกของเครื่องด้วย A-Frame 1.6.0 + AR.js 3.4.8 จุด A/B/C จะปักคงที่หลังจับตำแหน่งได้ จึงเดินหันกล้องไปดูแต่ละจุดได้ แถบด้านบนบอกพิกัด ความแม่นยำ GPS และระยะห่างจากแต่ละจุด

## ไฟล์ในโฟลเดอร์

| ไฟล์ | ใช้ทำอะไร |
| --- | --- |
| `index.html` | หน้าเว็บ AR |
| `models/3d_anime_character_girl_for_blender.glb` | โมเดลตัวละคร 3D |

## เปิดใช้บนมือถือผ่าน HTTPS ด้วย GitHub Pages

1. ลงชื่อเข้าใช้ GitHub แล้วสร้าง repository ชื่อ `gps` เลือก **Public**
2. ใน repository กด **Add file → Upload files** แล้วอัปโหลด `index.html`, `README.md` และโฟลเดอร์ `models` ทั้งโฟลเดอร์ เพื่อให้ไฟล์ GLB อยู่ที่ `models/3d_anime_character_girl_for_blender.glb` จากนั้นกด **Commit changes**
3. ไปที่ **Settings → Pages** เลือก **Deploy from a branch**, Branch **main**, Folder **/(root)** แล้วกด **Save**
4. รอ 1–2 นาที แล้วเปิดลิงก์ `https://parinratron-svg.github.io/gps/` บนมือถือ อนุญาตกล้องและตำแหน่งได้เลย ไม่ต้องใช้ Wi-Fi วงเดียวกับคอม

## แก้ผลงานของตัวเอง

1. เปิดหน้าเว็บบนมือถือและอนุญาต Location เพื่อใช้ GPS ของเครื่อง
2. ใน `index.html` ปรับ `data-offset-north` และ `data-offset-east` เพื่อเปลี่ยนระยะของแต่ละจุดจากพิกัดแรกที่ GPS อ่านได้ (หน่วยเป็นเมตร; ค่าเริ่มต้น A เหนือ 10 ม., B ตะวันออก 20 ม., C ใต้ 30 ม.)
3. จุดจะไม่ขยับตามเครื่องระหว่างใช้งาน แต่จะเริ่มตำแหน่งใหม่เมื่อรีเฟรชหรือเปิดหน้าเว็บอีกครั้ง
4. กด **Commit changes** รอ 1–2 นาที แล้วรีเฟรชบนมือถือ

## แก้ปัญหาเบื้องต้น

- **ไม่มีพิกัด / GPS ใช้ไม่ได้:** เปิดลิงก์ผ่าน HTTPS (เช่น GitHub Pages) หรือ localhost; การเปิดผ่าน HTTP ด้วย IP ของคอมพิวเตอร์มักถูกเบราว์เซอร์บล็อก เปิด Location ของมือถือ อนุญาตตำแหน่งให้ Chrome/Safari และลองออกไปที่โล่ง
- **iPhone:** หลังอนุญาตกล้องให้ **แตะหน้าจอ 1 ครั้ง** เพื่ออนุญาตเซนเซอร์ทิศทาง ถ้ายังไม่ได้ ไปที่ Settings → Safari → Motion & Orientation Access
- **วัตถุลอยไปมา / กระโดด:** เป็นธรรมชาติของ GPS มือถือ (คลาดเคลื่อน 5–20 เมตร) ดูค่า "ความแม่นยำ" บนแถบด้านบน ยืนนิ่ง ๆ ในที่โล่งสักครู่
- **ทิศผิด:** เข็มทิศมือถืออาจเพี้ยน หมุนมือถือเป็นรูปเลข 8 กลางอากาศ 2–3 รอบ
- **ไม่เห็นวัตถุทั้งที่ระยะถูก:** ลองหันรอบตัวช้า ๆ หรือปรับ `scale` ใน `index.html` (ค่าเริ่มต้น 3 เท่า) วัตถุที่ห่างเกินประมาณ 100 เมตรจะเล็กมาก
- **กล้องไม่เปิด:** เปิดใน Chrome หรือ Safari โดยตรง ไม่ใช่เบราว์เซอร์ในแอป LINE/Facebook
